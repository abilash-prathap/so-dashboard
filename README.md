# SO Dashboard

A simple support dashboard prototype built with static HTML, CSS, and JavaScript.

## Features

- Executive overview cards
- Open support request table
- Popular tag summary
- Recent activity feed
- Team workload bars

## Run locally

Open `index.html` in a browser, or serve the folder with a lightweight local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure

- `index.html` – dashboard layout
- `styles.css` – visual design and responsive layout
- `script.js` – mock data rendering
- `.gitignore` – ignores editor and OS files
